Project overview

DropLink — Secure File Sharing

The deployed DropLink homepage describes file sharing with encrypted cloud storage, a complimentary guest transfer, and an account-based personal vault.

What the deployed site describes

  • A guest can start with one complimentary file transfer without signing up.
  • An account provides access to additional uploads and a personal vault.
  • The interface describes encrypted cloud storage and share links.

These details are taken from the committed deployment copy and its included interface screenshots.

Repository and live preview

The repository contains the pre-rendered web build under /Vibe/ and DropLink screenshot assets. The build files identify a Next.js application.
